# 1.4 — Incident Console (SPA)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the SPA surface where ranked incidents are read and acted on.

**Deliverables**
- Ranked incident list; detail view: correlated signals, AI root cause + **evidence/queries**, matched
  runbook, similar past incidents, timeline.
- Severity encoded in form (stripe/pill), not just color.
- "Push to <channel>" actions (Teams first; ITSM in 1.7).
- Degrades cleanly when a root-cause narrative is absent (LLM off) — still shows signals + timeline.

**Acceptance**
- Console renders ranked incidents from 1.3; detail shows all sections.
- With no AI narrative, the console still fully functions.
- Responsive + tenant/role scoped.
