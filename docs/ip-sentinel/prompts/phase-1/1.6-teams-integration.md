# 1.6 — Microsoft Teams integration (first)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the **first** external integration — lowest friction (Graph/Azure AD already in use). Covers
staff + customer delivery.

**Deliverables**
- Post incidents (with root cause + evidence when present) to configured Teams channels via Graph.
- Per-tenant channel config in `integration_config`; respect tier + isolation.
- Dedupe (no duplicate posts per incident); update on status change.
- Reuse existing OAuth2/Graph token handling patterns.

**Acceptance**
- A new incident posts once to the correct tenant's Teams channel with context; a status change updates it.
- No cross-tenant leakage; config resolves secrets via DPAPI.
