# 1.2 — Triage / root-cause agent (LLM + RAG)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the differentiator — an AI root-cause explanation grounded in evidence and past incidents.

**Deliverables**
- For each incident (from 1.1): gather context via the read-only tools, retrieve the matching runbook
  + top-K similar past incidents (`kb_search`), and produce
  `{root_cause_hypothesis, evidence, severity, suggested_checks}`.
- **Cite the queries/evidence used**; label confidence; "insufficient data" path.
- Persist to the incident; expose via REST (1.3).
- **Graceful degradation:** if the LLM is unavailable, the incident still exists (from 1.1) and simply
  shows no AI narrative — no failure.

**Acceptance**
- A seeded incident gets a root-cause hypothesis with cited evidence + a matched runbook.
- With the LLM down, the incident is unaffected except the narrative is absent (test).
- Output is validated/structured before persist.
