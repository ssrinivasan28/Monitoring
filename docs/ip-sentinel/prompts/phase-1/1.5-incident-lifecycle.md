# 1.5 — Lightweight incident lifecycle

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** just enough workflow in-app — ITSM stays system-of-record (synced in 1.7).

**Deliverables**
- Incident states + transitions: acknowledge, assign, resolve; free-text **notes/comments**; timeline entries.
- Who/when recorded for each transition (audit).
- Status model designed to **map to ServiceNow/Jira** for two-way sync.

**Acceptance**
- A user can ack → assign → resolve with notes; every transition is timelined + audited.
- State model has a clean mapping to ITSM statuses (documented for 1.7).
