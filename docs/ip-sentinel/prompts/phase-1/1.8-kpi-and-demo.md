# 1.8 — Alert-noise KPI + correlation demo seed  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** instrument the **primary success metric** and seed the **flagship demo**.

**Deliverables**
- **Alert-noise reduction KPI:** track raw-alert count vs correlated-incident count per tenant/period;
  surface the ratio on the Fleet Overview + in reports.
- **Cross-platform correlation demo seed:** a reproducible scenario/fixture where an IBM i outage +
  its Windows fallout produce **one** incident with root cause — usable for demos and as a test.

**Acceptance**
- The KPI computes and displays correctly for a period with known raw alerts vs incidents.
- Running the seed yields a single cross-platform incident with a root-cause narrative (the demo).
