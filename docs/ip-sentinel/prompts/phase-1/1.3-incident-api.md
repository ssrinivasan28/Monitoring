# 1.3 — Incident persistence & REST API

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the tenant-scoped API the Incident Console and integrations consume.

**Deliverables**
- REST endpoints: list/rank incidents (by severity, recency), get detail (signals, root cause,
  evidence, runbook, similar incidents, timeline), filter by tenant/platform/status.
- Ranking + pagination; consistent DTOs.
- All endpoints tenant-scoped + audited; customer visibility respects isolation.

**Acceptance**
- List/detail return correct, tenant-scoped data with ranking + paging.
- A customer sees only their incidents; staff can span tenants (test).
