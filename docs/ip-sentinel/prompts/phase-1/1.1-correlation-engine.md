# 1.1 — Correlation engine (rule-based, no-LLM)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Collapses simultaneous breaches into single incidents **deterministically** — the noise-reduction
core, and it must run with the LLM off (1.2 enriches later). Emphasize **cross-platform** grouping,
which is the flagship demo.

## Scope
**In:** breach ingestion, grouping rules, incident/signal/correlation/timeline persistence, suppression.
**Out:** AI root cause (1.2), notifications (1.6/1.7), UI (1.4).

## Dependencies
- 0.1 schema, 0.4 gateway. A simple **topology map** (which Windows host(s) relate to which IBM i
  system) per tenant — config table or `integration_config`; used for cross-platform linking.

## Deliverables

### 1. Breach ingestion
- Poll active breaches per tenant from Prometheus alert-state metrics the monitors expose (and/or the
  `alerts` table). Scheduler interval configurable.

### 2. Grouping rules (deterministic)
An incoming breach joins an existing open incident when, for the **same tenant**:
- it falls within a **time window** (configurable, e.g. 5 min) of the incident's signals, **AND**
- it is **related** by system/topology (same host, or IBM i↔Windows pair from the topology map).
Otherwise open a new incident. Persist `incidents`, `incident_signals`, `correlations`, `incident_timeline`.

### 3. Suppression (generalize the monitors' existing logic)
- **Dedupe** identical repeat signals; **N-consecutive-breach** before opening (configurable);
  **flap** detection (rapid open/clear) → hold/annotate rather than churn.

### 4. Severity (rule-based)
- Initial severity from signal count/kind (refined by 1.2 later). No LLM.

## Constraints / gotchas
- **Never merge across tenants** — grouping is always tenant-scoped.
- Runs fully with the LLM disabled.
- Make window/threshold/topology all config, not hardcoded.

## Testing
- Multiple simultaneous signals (incl. one IBM i + one related Windows) in a tenant ⇒ **one** incident.
- Two tenants breaching at once ⇒ **two** incidents, no cross-tenant merge.
- Flapping signal ⇒ suppressed, not repeated incidents.
- Runs with the provider disabled (no LLM calls made).

## Acceptance
- [ ] Cross-platform simultaneous breaches collapse to one incident with all signals + a timeline.
- [ ] Tenant isolation holds; suppression works.
- [ ] Zero LLM dependency.
