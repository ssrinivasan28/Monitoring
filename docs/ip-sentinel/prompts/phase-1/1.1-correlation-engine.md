# 1.1 — Correlation engine (rule-based, no-LLM)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** collapse simultaneous breaches into single incidents — **deterministically, without the LLM**
(so this works even when AI is unavailable; the LLM enriches later in 1.2).

**Deliverables**
- Ingest active breaches from federated Prometheus alert-state metrics (per tenant).
- Group by **time window + system/topology + tenant** into one incident; persist `incidents`,
  `incident_signals`, `correlations`, `incident_timeline`.
- Dedupe, N-consecutive-breach, and flap suppression (generalize the monitors' existing logic).
- Emphasize **cross-platform** grouping (IBM i signal + related Windows signal → one incident).

**Acceptance**
- Multiple simultaneous signals across monitors/platforms in one tenant yield **one** incident (test).
- Runs with the LLM disabled.
- Tenant isolation: signals never merge across tenants.
