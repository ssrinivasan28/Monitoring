# 0.1 — Data model & migrations

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the PostgreSQL 18 schema and migration tooling for the whole platform.

**Deliverables**
- Flyway migrations; enable `pgvector`.
- JPA entities / tables: `tenants`, `users`, `roles`, `entitlements` (tier: Basic/Pro), `monitors`,
  `alerts`, `incidents`, `incident_signals`, `correlations`, `incident_timeline`, `agent_runs`,
  `tool_calls`, `feedback`, `kb_docs`, `kb_chunks(embedding vector)`, `forecasts`,
  `threshold_recommendations`, `cost_ledger`, `model_config`, `integration_config`, `reports`.
- Every tenant-scoped table carries a `tenant_id`; add indexes for tenant + time-range queries.
- Retention: document/param **13-month** horizon for time-bound tables (incidents/audit); Prometheus/Loki
  retention handled in 0.11.

**Acceptance**
- `mvn`/Testcontainers boot applies all migrations cleanly against Postgres 18 with `pgvector` enabled.
- A round-trip insert/select works for `incidents` + `kb_chunks` (vector similarity query returns rows).
