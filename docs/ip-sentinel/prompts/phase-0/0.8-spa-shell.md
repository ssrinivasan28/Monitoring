# 0.8 — SPA shell (auth, tenants, brand, responsive)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the React/TS application shell everything else plugs into.

**Deliverables**
- Login flows for **staff SSO** and **customer invite+MFA** (backend from 0.2).
- **Tenant switcher** (staff span tenants; customers pinned to theirs), app navigation, and role/tier-aware menu.
- **Island Pacific brand** (blue `#0057B8` / amber `#F5A300`, white bg), **responsive** (phone→desktop).
- API client with tenant context; auth guards; error/empty/loading states.
- Served by Spring Boot (bundled static) — single service, single port.
- **Admin › Data Sources** (staff-only): list / add / edit / enable-disable / delete a tenant's metrics
  & logs sources (name, kind `prometheus|thanos|loki`, URL, auth), with a **Test connection** button
  (calls the 0.4 admin API). Supports **multiple sources per tenant** so new monitoring can be added
  later. Secrets entered here are stored protected and **never echoed back**.

**Acceptance**
- Staff and customer users each land in a correctly scoped shell; tier-gated nav items hidden/disabled for Basic.
- Layout is usable on mobile and desktop; brand palette applied; keyboard-navigable.
- Built SPA is served by the backend JAR at `/`.
