# 0.10 — Pilot dashboards (uPlot parity)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** metric dashboards in the SPA that reach parity with the existing Grafana JSON for the two
pilot monitors — proving we can retire Grafana.

**Deliverables**
- **uPlot** time-series panels; time-range + tenant selectors; tabular-nums, legend, grid, endpoint emphasis.
- Parity with `grafana-dashboards/windows-monitor.json` and `win-service-monitor.json`.
- All data via the **0.4 query gateway** (never direct to Prometheus).
- Log panel/link into the Log Explorer for the same window.

**Acceptance**
- Side-by-side, the SPA panels match the Grafana panels for the pilot monitors (same series/values).
- Panels are responsive and performant; tenant scoping enforced.
- No dependency on Grafana at runtime.
