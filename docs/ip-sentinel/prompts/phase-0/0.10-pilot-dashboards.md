# 0.10 — Pilot dashboards (uPlot parity)  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Prove Grafana can be retired by rebuilding the two pilot dashboards in the SPA with **uPlot**, at
parity. Second half of the fleet-view MVP.

## Scope
**In:** a reusable uPlot time-series component, the two pilot dashboards, time-range + tenant selectors,
a link into the Log Explorer.
**Out:** other monitor dashboards (replicate the pattern later), alerting.

## Dependencies
- 0.4 query gateway, 0.8 SPA shell, 0.9 (drill-down target).

## Deliverables

### 1. Chart component
- A `TimeSeriesChart` wrapper around **uPlot**: area fill, faint grid, emphasized endpoint, legend,
  `tabular-nums`, responsive (resize observer), brand colors, light theme.
- Accepts a PromQL result (matrix) from the gateway; handles gaps/stale.

### 2. Pilot dashboards (parity spec = the existing Grafana JSON)
- Replicate the panels defined in `grafana-dashboards/windows-monitor.json` and
  `grafana-dashboards/win-service-monitor.json` — same series, units, and layout.
- For each Grafana panel, map its PromQL target → a gateway query → a `TimeSeriesChart` (or stat/table).
- **Time-range selector** (last 1h/6h/24h/7d/13mo) and **tenant selector**.

### 3. Cross-links
- From a panel/anomaly, link to the **Log Explorer** for the same time window + tenant.

## Constraints / gotchas
- All queries through **0.4** (tenant-scoped, audited) — never direct to Prometheus.
- Match units/scales to the Grafana panels so parity is verifiable side-by-side.
- Body must not scroll horizontally; wide panels scroll within their own container.

## Testing
- Parity check: for a fixture dataset, SPA panels render the same series/values as the Grafana panels.
- Selector test: changing time-range/tenant re-queries via the gateway with correct params.
- Responsive: panels usable on mobile + desktop.

## Acceptance
- [ ] SPA reproduces the pilot Grafana dashboards at parity (side-by-side).
- [ ] Time-range + tenant selectors work; queries go through 0.4.
- [ ] No Grafana dependency at runtime for these dashboards.
