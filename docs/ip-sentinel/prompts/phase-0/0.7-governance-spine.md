# 0.7 — Governance spine (audit, redaction, cost, SOC 2)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the cross-cutting controls that wrap **every** LLM/tool call — foundational, not bolted on.

**Deliverables**
- **Audit:** append-only `agent_runs` + `tool_calls` (prompt, tools, output, tenant, user, timestamps).
  **Immutable + retained** per SOC 2 (no in-place update/delete; defined retention).
- **PII/secret redaction** applied to context **before** any LLM call (esp. the Claude path); tested
  against seeded secrets/PII.
- **Cost/token metering** → `cost_ledger`; **per-tenant quotas** with enforcement + routing hooks.
- Expose an **audit query API** (staff-only) for evidence/review.

**Acceptance**
- Every agent/tool call produces an immutable audit row; deletion/update attempts are rejected (test).
- Redaction strips seeded secrets/PII before send (network-capture or spy test).
- Token cost is recorded per call/tenant; exceeding a quota is enforced.
