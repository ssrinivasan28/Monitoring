# 0.11 — Data-plane & packaging

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** wire existing installs to the central platform and package it the WinSW way.

**Deliverables**
- **Prometheus remote-write/federation** in `resources/prometheus/prometheus.yml`, tenant =
  `ClientInstanceId`; secure the channel (mTLS/token).
- Central metric **retention 13 months** (Prometheus retention or Thanos + object storage); Loki
  retention to match.
- **Drop Grafana** from the MonitoringServer bundle (only after 0.9/0.10 parity).
- Installer: new **"AIOps Platform"** role; `IPMonitoring_AIOpsPlatform` WinSW service; deploy
  `application.yml` with `onlyifdoesntexist`; extend `build-installer.ps1`.
- `application.yml` keys: `server.port`, Postgres, Prometheus/Loki URLs, LLM provider, Azure AD, tenant id.

**Acceptance**
- A client's Prometheus remote-writes to central; series carry the tenant label.
- `build-installer.ps1` produces the platform artifact + installs the WinSW service; config preserved on upgrade.
- The 21 monitors are unchanged (git diff = new module + prometheus.yml + installer only).
