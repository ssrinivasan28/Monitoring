# 0.2 — Authentication (staff + customer)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** dual authentication — staff and external customers.

**Deliverables**
- **Staff:** Azure AD **OIDC SSO**.
- **Customers:** **invite-based accounts + mandatory MFA**; account lifecycle (invite, activate,
  reset, disable).
- **Optional federated per-tenant SSO** (SAML/OIDC) a customer can connect for their own directory.
- Unified session/principal model that carries `user`, `tenant(s)`, `role`, and `tier`.
- Login UI states in the SPA shell come later (0.8) — here expose the backend auth + token/session APIs.

**Acceptance**
- A staff user logs in via Azure AD; a customer user logs in via invite+MFA; a federated test IdP works.
- Sessions resolve to the correct tenant(s) and role; MFA is enforced for customer accounts.
- Secrets (client secrets) resolved via `CredentialProtector` — no plaintext.
