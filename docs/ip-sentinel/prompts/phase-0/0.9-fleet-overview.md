# 0.9 — Fleet Overview — capacity headroom  ⭐

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the **top-priority** screen — every client's health at a glance, driven by **capacity headroom**.

**Deliverables**
- Backend **headroom score** per tenant from a **weighted blend** of: IBM i ASP/disk, Windows disk,
  CPU, memory/job-queue depth (weights configurable, ASP highest).
- **Hard critical override:** any single input in a critical band forces the client to critical,
  regardless of the blend (so a full disk can't be averaged away).
- Fleet grid in the SPA: one card/row per tenant, red/amber/green by headroom, drill-down to detail.
- Filter/sort by client, platform, severity. Fully deterministic — **no LLM**.

**Acceptance**
- Grid shows all tenants with correct headroom color from live metrics (via the 0.4 gateway).
- A single critical resource turns the client critical even when other inputs are healthy (test).
- Works with the LLM disabled.
