# 0.6 — Read-only tool registry

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the read-only tools agents call, dispatched uniformly by both LLM providers.

**Deliverables**
- `promql_query`, `loki_query` (via the 0.4 gateway — inherit tenant scope + audit).
- `ibmi_sql` — **SELECT-only** against DB2/QSYS2; reuse the JDBC pattern from
  `ibmsqlthresholdmonitoring/SqlThresholdService.java`; parameterized; reject non-SELECT.
- `service_status` / `list_monitors`; `read_config` (secrets redacted).
- `kb_search` — pgvector similarity over `kb_chunks` (tenant-scoped).
- Each tool call is audited to `tool_calls` (0.7).

**Acceptance**
- `ibmi_sql` rejects INSERT/UPDATE/DELETE/DDL (test); returns rows for a SELECT.
- All tools enforce tenant scope; `read_config` never returns secret values.
- Every invocation writes a `tool_calls` audit row.
