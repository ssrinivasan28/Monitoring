# 0.5 — LLM provider layer (Claude + local, AI-optional)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** one pluggable LLM abstraction with routing + fallback — and a hard guarantee the platform
runs when it's absent.

**Deliverables**
- `LlmProvider` interface; `ClaudeApiProvider` (Messages API, native tool-use) and
  `LocalModelProvider` (OpenAI-compatible: Ollama/vLLM).
- **Routing + fallback** (Claude ↔ local) and a **disabled/unavailable mode**.
- Config in `application.yml` (`provider`, endpoints, model, keys via DPAPI).
- Pluggable **embeddings** provider for RAG (used by 0.6/3.3).

**Acceptance**
- Same call works against `provider: claude` and a local endpoint (same tool-call flow).
- With the provider **unavailable**, callers get a clean "AI unavailable" result — no exceptions bubble
  to the UI; non-AI features are unaffected (add a test simulating provider down).
