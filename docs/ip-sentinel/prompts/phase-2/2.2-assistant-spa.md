# 2.2 — Assistant SPA (streaming, tool trace)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the in-app chat surface.

**Deliverables**
- Streaming chat over **WebSocket**; shows the agent's **tool/query trace** inline.
- Conversation history; copy/cite affordances; responsive.
- Hidden/disabled for Basic tenants (gating from 2.4); clear upsell state.

**Acceptance**
- A question streams a response with the tool trace visible.
- Basic-tier users don't see a working Assistant; Pro users do.
