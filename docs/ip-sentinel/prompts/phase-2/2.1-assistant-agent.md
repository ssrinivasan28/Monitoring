# 2.1 — Assistant agent (agent loop, cites queries)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the conversational agent — read-only Q&A over live data + memory. (Pro-tier feature; gating in 2.4.)

**Deliverables**
- Agent loop over the read-only tool registry + `kb_search`; multi-step tool use.
- Answers **cite the exact queries/tools** run.
- Tenant + role scoped; every turn redacted, audited, cost-metered.
- Streaming-ready output for the SPA/Teams surfaces.

**Acceptance**
- "Which clients had job-queue backups in the last 24h, and what was running?" produces a correct,
  ranked answer from a real PromQL + `ibmi_sql` call, with the queries shown.
- A user cannot pull another tenant's data through the agent (test).
