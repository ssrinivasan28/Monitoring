# 3.1 — Baseline & anomaly detection (statistical)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** catch what static thresholds miss — **statistical, no LLM** (works AI-off).

**Deliverables**
- Learn per-series baselines + seasonality from Prometheus history (13-mo window available).
- Emit anomaly signals; produce `threshold_recommendations` (**never rewrite** `.properties`).
- Tenant-scoped; feeds Insights (3.5) and can raise incidents via 1.1.

**Acceptance**
- A recurring benign spike yields a threshold **recommendation**, not a false alert (test).
- Runs with the LLM disabled.
