# 3.3 — Knowledge Curator (RAG ingestion)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** build the searchable memory that grounds triage + Assistant.

**Deliverables**
- On runbook upload / incident resolve: chunk + embed into `kb_docs`/`kb_chunks` (pgvector), tenant-scoped.
- Summarize resolved incidents into reusable memory entries.
- Curation UI hooks (managed in the KB module); **strict per-tenant isolation** (no shared learning).

**Acceptance**
- Uploading a runbook makes it retrievable via `kb_search` for that tenant only (test isolation).
- A resolved incident becomes a similar-incident match for a later related incident.
