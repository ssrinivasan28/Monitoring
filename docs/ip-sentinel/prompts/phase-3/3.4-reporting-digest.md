# 3.4 — Reporting / Digest agent (daily/weekly/monthly)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** scheduled customer-facing health/SLA reports. (New agent — add to the roster.)

**Deliverables**
- **Daily digest**, **weekly digest**, **monthly SLA report** per tenant (13-mo history enables YoY/monthly SLA).
- Include the **alert-noise reduction KPI**, capacity headroom, incidents, uptime/SLA, trends.
- **AI-written prose when available; templated fallback when the LLM is off** (graceful degradation).
- Deliver via **email, in-portal, Teams**; on-demand export too.

**Acceptance**
- Each cadence generates a correct tenant-scoped report and delivers on the configured channels.
- With the LLM disabled, reports still generate using the templated fallback (test).
