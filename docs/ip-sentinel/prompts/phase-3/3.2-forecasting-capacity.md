# 3.2 — Forecasting / capacity (feeds fleet view)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** proactive capacity forecasts — **statistical, no LLM** — that also enrich the Fleet Overview.

**Deliverables**
- Project disk/ASP fill dates, cert-expiry runway, job-duration drift; persist `forecasts` with
  projected date + driver.
- Feed the **capacity-headroom** signal (0.9): escalate a client early when a resource trends to full soon.
- Surface in Insights (3.5).

**Acceptance**
- A seeded upward trend with no static breach produces a forecast with a plausible date.
- The Fleet Overview reflects an early-warning escalation from a forecast.
- Runs with the LLM disabled.
