# 3.5 — Insights (SPA)

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

**Goal:** the SPA surface for proactive signals.

**Deliverables**
- Anomaly feed, forecasts, and **threshold recommendations** with **accept/dismiss** (writes `feedback`
  only — never edits `.properties`).
- Links into related dashboards/incidents; tenant/role scoped; responsive.

**Acceptance**
- Insights lists anomalies/forecasts/recommendations for the tenant.
- Accept/dismiss records `feedback` and adjusts future scoring; no config file is modified (test).
