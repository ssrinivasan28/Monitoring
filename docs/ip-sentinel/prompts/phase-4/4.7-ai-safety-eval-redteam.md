# 4.7 — AI safety evaluation & red-team

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Make the AI outputs trustworthy — the highest-priority AI gate for a product that makes ops claims.

## Deliverables
- A **regression eval set** built from real (anonymized, single-tenant) incidents; run in CI with
  quality thresholds; track Claude vs local.
- **Adversarial / prompt-injection** test suite: tool-returned data (logs, IBM i rows, configs) can
  **never** change the agent's actions or exfiltrate cross-tenant data.
- **Output-validation** coverage: no uncited root cause; enforce the "insufficient data" path;
  confidence surfaced.
- Guardrail regression gate in CI.

## Acceptance
- [ ] Eval set runs in CI; triage quality meets the threshold on both providers.
- [ ] Injection attempts fail to alter actions or cross tenants (tests).
- [ ] No uncited/unvalidated root cause is ever persisted (test).
