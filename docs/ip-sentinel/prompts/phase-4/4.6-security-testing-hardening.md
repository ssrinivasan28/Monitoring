# 4.6 — Security testing & hardening

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Close the security gates an enterprise review / SOC 2 will require.

## Deliverables
- **SAST + dependency scanning + secret scanning** in CI (fail the build on criticals).
- **DAST** against a running instance; a **threat model** for the platform.
- SPA hardening: **security headers** (CSP, HSTS), **CSRF/CORS** posture, secure **session** management.
- **Pen-test** prep + tracked remediation of findings.
- Verify `ibmi_sql` SELECT-only, tenant isolation, and no-plaintext-secrets under adversarial input.

## Acceptance
- [ ] CI security gates pass; no unresolved critical/high findings.
- [ ] Headers/CSRF/CORS/session verified; DAST clean of highs.
- [ ] Pen-test findings triaged and remediated (or risk-accepted with sign-off).
