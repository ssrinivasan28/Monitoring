# 4.5 — Performance & load testing

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Prove the platform meets its scale targets and set capacity guidance.

## Deliverables
- **Load + soak test** suite at target scale: **< 25 tenants**, expected metric/log ingest rate,
  concurrent SPA users, agent/triage throughput.
- **Performance budgets** (API p95, dashboard load, triage latency) as **CI gates**.
- **Capacity-planning doc** per topology (CPU/RAM/disk; GPU sizing for the local model).
- Postgres connection-pool + query tuning; Thanos/Loki retention sizing validated for 13 months.

## Acceptance
- [ ] Platform meets the defined latency/throughput budgets at target scale.
- [ ] A soak test runs stable (no leak/growth) over the agreed duration.
- [ ] Capacity-planning numbers documented and referenced by DEPLOYMENT.md.
