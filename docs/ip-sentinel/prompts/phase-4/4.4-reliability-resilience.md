# 4.4 — Reliability & resilience hardening

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Make the platform behave under load and partial failure.

## Deliverables
- **Rate limiting** (API + LLM calls) and **backpressure** on ingestion.
- **Circuit breakers** around external integrations and the LLM provider.
- **Idempotent** integration delivery (no duplicate tickets/pages/cards); retry with **dead-letter**.
- End-to-end verification of **AI-optional graceful degradation** (LLM down ⇒ platform serves
  dashboards, threshold incidents, alerts, forecasts).

## Acceptance
- [ ] A request burst is rate-limited (not silently dropped); backpressure holds.
- [ ] A down integration trips its breaker and dead-letters; recovery drains cleanly.
- [ ] Retries never duplicate an outbound action (idempotency test).
- [ ] LLM outage system test: platform stays fully up for non-AI features.
