# 4.8 — Compliance (SOC 2) & accessibility

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Evidence and access gates for **SOC 2 Type II**, plus an accessible UI for enterprise buyers.

## Deliverables
- **Audit immutability + retention** proven (tamper attempts rejected; retention enforced).
- **Access reviews** + **change-management** records; **subprocessor list** (incl. Anthropic on the
  Claude path); **evidence-collection** hooks/exports for the auditor.
- **Data-residency** posture documented per topology (on-prem/local model = no egress).
- **Accessibility (WCAG 2.1 AA)** pass on the SPA: keyboard nav, focus states, contrast, ARIA;
  i18n scaffolding if required.

## Acceptance
- [ ] Audit tamper attempts are rejected and retained per policy (test).
- [ ] SOC 2 control evidence is exportable; subprocessor + access-review docs exist.
- [ ] SPA passes an accessibility audit (WCAG 2.1 AA) on the key screens.

> Note: SOC 2 **Type II** also requires operating these controls over an audit period — a process,
> not just code. This chunk delivers the technical controls + evidence hooks that make it possible.
