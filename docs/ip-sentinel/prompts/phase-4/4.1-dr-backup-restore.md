# 4.1 — DR / Backup & Restore

*Prepend [`00-shared-preamble.md`](../00-shared-preamble.md).*

## Context
Production data safety for the platform's state (incidents, audit, knowledge base, config).

## Deliverables
- Automated **PostgreSQL backups** (+ PITR where supported); scheduled and monitored.
- **Tested restore** procedure with a documented **RTO/RPO**; a restore drill script.
- Back up the **knowledge base / embeddings** and `application.yml` (secrets excluded/handled).
- Document acceptable **Prometheus/Loki** loss on DR (reconstructable from agents / remote-write).
- A **DR runbook** (start/stop, restore, failover) in `docs/`.

## Acceptance
- [ ] A restore drill recovers the DB to a chosen point-in-time (test/documented).
- [ ] RTO/RPO stated and met by the drill.
- [ ] Backup jobs are scheduled and self-monitored (alert on failure).
